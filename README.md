# Simple Banking Simulation

## Current Progress

This initial version contains two separate console applications:
- `admin_app.cpp` - Administrator banking system
- `customer_app.cpp` - Customer banking service

The current version includes:
- Separate administrator and customer login screens
- Separate administrator and customer menus
- Menu navigation loops
- Input validation for menu choices
- Logout options
- Placeholder sections for future banking features
